SOP: Processing Electronics Returns

Use this procedure at the register or customer service desk when a customer requests to return an electronics item. See the Electronics Returns Policy for eligibility rules.

Procedure

  1. Look up the order or verify the receipt, and confirm the purchase date is within the eligibility window.
  2. Inspect the item for completeness: original packaging, cables, and accessories.
  3. Confirm the item shows no signs of damage beyond normal wear.
  4. If eligible, process the return in the POS system and issue the refund to the original payment method.

Exception

If the item exceeds $500 in value and the customer has no receipt or other proof of purchase, do not process the return at the register.

Escalation

Escalate to the Returns Specialist queue via the Associate Support Tool, case type High-Value No-Receipt Return. Provide the item description, estimated value, and reason the customer could not produce a receipt.
