Walmart+ Membership Extended Returns

Walmart+ members receive an extended return window on eligible electronics purchases, on top of the standard Electronics Returns Policy window.

Eligibility

Active Walmart+ members receive an additional 15 days beyond the standard electronics return window, applied automatically at checkout when the account is recognized as an active member.
