FAQ: Electronics Returns

Q: How long do I have to return a TV or laptop?

A: See the Electronics Returns Policy for the current eligibility window and receipt requirements.

Q: Can I return an opened electronics item?

A: Yes, as long as all original accessories, cables, and packaging are included and the item is not damaged.

Q: What if I lost my receipt?

A: Order lookup can often substitute for a paper receipt. For high-value items without any proof of purchase, the associate may need to escalate per the Electronics Returns SOP.
